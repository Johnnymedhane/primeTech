# PrimeTech 🚀

PrimeTech is a modern, responsive frontend web application built with **React** and **Vite**.

Live site: https://primete.netlify.app/

## ✨ Features

- **Multi-page web application** with Home, About Us, Courses, Projects, Contact, and detailed views
- **Dynamic courses & projects sections** with detailed information pages, powered by Redux state management
- **Contact form** with validation and toast notifications using React Hook Form
- **Student testimonials** section showcasing client success stories
- **Interactive map integration** for location display
- **Responsive layout** with animated mobile navigation menu
- **Lazy-loaded pages** with Suspense for optimized performance
- **Reusable UI components** (Cards, Buttons, Forms, etc.)
- **Client-side routing** with React Router and dynamic page titles
- **Redux Toolkit** for efficient state management across courses, projects, and user data
- **Form validation** and error handling with toast notifications
- **Production-ready build** with Vite for fast compilation and optimized bundling

## 🛠 Tech Stack

- **React**
- **Vite**
- **React Router**
- **CSS Modules**
- **JavaScript (ES6+)**
